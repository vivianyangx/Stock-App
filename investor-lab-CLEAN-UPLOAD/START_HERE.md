# Investor Lab — clean upload

This folder is the complete Streamlit app. Do not place it inside an older app folder.

## Upload to GitHub

1. Create a new empty public repository, or delete the old duplicate app folders from the repository you want to reuse.
2. Open this folder and upload **all files and folders inside it** to the repository root.
3. Keep `model_artifacts/professional_v1.json` inside the `model_artifacts` folder.

The repository root should look exactly like this:

```text
stock_app.py
ml_engine.py
requirements.txt
README.md
START_HERE.md
MODEL_CARD.md
DATA_SOURCES.md
model_artifacts/
  professional_v1.json
```

## Streamlit settings

- Branch: `main`
- Main file path: `stock_app.py`

Do not use a path beginning with `investor-options-lab/`; those were older duplicate folders.
